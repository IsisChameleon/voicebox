One pipeline, two bots, and a slot where the LLM used to be

pipecat names parties by direction, not identity. Knowing that turns every stage name in this pipeline from confusing into obvious.

Describes the pipeline after the Phase 1–3 changes in docs/specs/2026-08-06-decouple-transcripts-from-turn-closure.md

Why the names invert

pipecat labels parties by direction. Whoever's audio comes in is the "user"; whoever the pipeline speaks as is the "bot" or "assistant".

In voicebox the incoming audio belongs to the app bot under test, so user_aggregator is the app bot's. The pipeline speaks as the tester, so assistant_aggregator is ours.

Every stage above the empty slot serves the app bot. Every stage below it serves the tester.

Why tester text starts at the top

queue_frames() is pipecat's supported injection point and it enqueues at the source — there is no way to inject partway down.

So the tester's text walks past vad, stt and user_aggregator to reach the TTS. Those stages inspect it, match nothing, and forward it untouched.

Traversing is not aggregating. The app bot's aggregator never accumulates the tester's words, and never gates them — it just hands them along.

Where the LLM went

A normal pipecat pipeline puts an LLM between the two aggregators: it reads the assembled user context and emits the text the TTS will speak.

voicebox has no LLM in-process. Claude plays that part over MCP, so speak() hand-builds the same frame triplet the stage would have emitted — LLMFullResponseStartFrame, LLMTextFrame, LLMFullResponseEndFrame.

The app bot's aggregator still assembles a context, but nothing reads it.

Where each event comes from

app_bot_speech_*VAD frames, seen by the pipeline observer. Instant and hardware-independent.
app_bot_transcriptThe TranscriptionFrame, seen by the observer at the stt → user_aggregator hop. Arrives when Whisper finishes; the timestamp comes from the observer's own VAD log, not from any aggregator.
tester_speech_*The tester's playout frames from the output transport.
tester_transcriptEmitted by speak() itself — ground truth, never round-tripped through STT.
